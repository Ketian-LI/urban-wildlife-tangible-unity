# 2026-09-12 开发记录

## 第四类人类角色与多样性

- 将S001从3类6名人类扩展为4类8名：Walker、Dweller、Visitor与Wheelchair User各2名。
- 第四类采用年长黑人女性手动轮椅使用者，锈橙外套、深公园绿车架、鼠尾草绿长裤与暖木色推圈；与现有年轻男性和女性角色在年龄、肤色、轮廓及行动方式上形成清晰差异。
- Wheelchair User沿入口A到出口B完整通行主路，预测试速度暂定5.5 cm/s；不绕行Food Hotspot，也不把玩家行为解释为直接控制角色。
- 新增1张透明待机Sprite和4张透明侧视推进Sprite，循环为发力、回手、发力、回手；移动方向改变时由Unity水平翻转整张角色图。
- UI人物统计增加Wheelchair User，运行日志同时报告四类人数；木制Token边框、调色材质和通行得分继续复用现有系统。Human Trace为该角色绘制成对短轮胎压痕，而不是不合理的鞋印。

## 边界与验证

- 当前只让无障碍通行需求在视觉和路线速度上可见；尚未模拟坡度、路缘、轮椅转弯半径或法定最小净宽，不能据此声称完成无障碍合规评估。
- Unity批处理验证确认8名人类均完成路线，5张新Sprite可加载、透明、比例有效，轮椅4帧推进序列与木制Token显示均通过。

## GDD V3 迁移启动

- 新版设计基线改为多物种城市片区建设即时策略游戏；现有公园Vertical Slice保留为可运行技术底座，并按独立批次迁移。
- 已建立GDD V3迁移清单，明确城市数据模型、五类建筑Token、道路候选、人流与车辆、环境压力、四物种、五阶段以及Trace/UI的实施顺序。
- 移除Confirm阶段的两道预测选择题及其Run门槛。约束通过后可直接Start Run，Observe只描述实际结果与Trace交叠。
- 为避免破坏已有研究日志读取，旧预测字段暂时保留并写入`Not set`，待城市日志schema升级时统一移除。

## 城市片区数据底座

- 新增 `CityState` V0.1，将 Building、GreenPatch、VehicleRoad、PedestrianLink 与 WasteSystem 作为后续城市模拟的共享数据层。
- Building 保存 Housing、Origin、Destination、Vehicle、Waste、Anthropogenic Food、Disturbance 与 Footprint；GreenPatch 保存类型、PublicPark、Shelter、Natural Food、Human Disturbance 与 Patch Size。
- VehicleRoad 与 PedestrianLink 明确分离，并记录 ExistingMap、AutoGenerated、ScreenEdited 或 LegacyAdapter 来源，避免重新把实体彩带当成机动车道路。
- 新增城市状态验证器与 JSON Schema，检查唯一 ID、归一化坐标、网络几何、建筑引用、数值范围和 Natural Food 保留原则。
- 旧 S001 每次确认布局后会旁路生成兼容 CityState，旧场景的人类、动物和 UI 逻辑保持不变，为后续逐批替换提供稳定接口。
