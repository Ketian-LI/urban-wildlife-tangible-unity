# 2026-09-16

## 建造与活动信息视图

- Build模式新增地图内浮动卡片，显示选中建筑的用途、住房/交通/垃圾等影响，并复用现有预览确认与取消流程。
- 只有Build模式接受地图放置点击，避免在信息、轨迹和暂停操作时误建建筑。
- Trace模式新增Normal / Human / Animal / Combined四档数据视图；聚合数据继续来自城市观测记录，`H`快捷键保持动物热点语义。
- 动物页四种物种均可选择，显示常见度、行为标签及简短生态说明。
- Roadkill和WasteOverflow接入中央事件弹窗，确认后仅关闭当前事件。
- Unity验证新增建造卡、轨迹选择条、事件弹窗位置以及人类/综合数据模式切换检查。

## 时间、主菜单与结算

- 顶部新增Pause / 1× / 2× / Season时间控件；四季可以循环切换，年份仍由城市发展阶段决定。
- 左上返回键接入主菜单，包含Continue、New Game、Settings和Quit；设置页复用现有中英文切换。
- 工具页新增“查看结算”和“主菜单”，不要求玩家等待自动结束。
- 结算页以实时城市发展、出行、垃圾管理、绿地连通和动物安全生成分项及总分，提供View Map与Play Again。
- 主菜单和结算覆盖层会禁用底层地图与侧栏按钮；退出后恢复进入覆盖层之前的暂停状态。
- Unity验证覆盖2×/1×/暂停、季节循环、主菜单继续及结算返回状态。

## 信息面板与全地图活动视图

- Info主导航现在将右侧栏切换为城市状态、动物与事件三页；城市状态读取五维平衡分数，事件页读取最近四条真实城市动态。
- Human、Animal与Combined不再借用右下角小地图，而是在主地图上使用轻遮罩、聚合热点和连续路径显示活动分布。
- 右下角卡片固定为Animal Hotspots，只读取动物样本；H键仅控制该卡片的动物热点开关，不再改变当前Trace视图。
- `CityTraceVisualizer`同时维护人类与动物的18 × 12独立聚合结果，供全地图视图和动物热点卡分别读取。
- Unity烟雾检查新增Info三页切换、全地图活动层以及人类/动物分层聚合验证。

## 建筑放置预览

- 桌面建造预览改为显示建筑真实占地和半透明建筑本体，不再只显示抽象青色区域。
- 可建位置使用绿色填充与边线；道路、已有建筑或地图边界冲突使用红色。
- 预览不再绘制被建筑覆盖的18 × 12后台格框，只显示与实际碰撞、清林和接路共用的连续占地，避免跨格时出现“显示面积大于实际面积”的误导。
- Desktop版允许几何上互不重叠的建筑共享同一个生态统计格，格内记录多个建筑引用并支持独立拆除；后台格不再额外扩大禁建范围。
- 无效红色预览可直接用下一次地图点击替换，不需要先点取消；有效绿色预览仍需确认或取消。
- 清林显示继续严格采用建筑真实占地与窄幅接入道路，不恢复整格白洞。
- 右侧栏增加1602 × 985窗口边界验证，保证运行时侧栏矩形完整落在屏幕内。
- 本轮只调整无需摄像头的Desktop流程，Camera扫描版保持现状，等待Desktop版本定稿后再同步评估。

## 建筑比例与后期密度

- 根据当前截图与成熟城市参考图的地图宽度重算视觉比例；独栋保持0.72，公寓缩为0.56，市场缩为0.72，社区设施缩为0.66。
- 只修改Sprite表现尺寸，四类建筑的真实占地、道路避让、清林范围和自动接路起点保持不变。
- Desktop模式在实体库存编号用完后自动分配仅限桌面输入的虚拟编号，可继续重复建设同类建筑，城市容量提高到72栋。
- 成熟城市阶段改为第23栋建筑时进入，使Early / Mid / Late的密度差异更接近参考图。
- Camera扫描仍严格限制实体库存，任何桌面虚拟编号都会被拒绝；两种输入模式不会混用编号。
- Unity烟雾检查覆盖四类视觉比例、72栋容量、虚拟编号生成、Camera隔离和原有放置建造流程。
