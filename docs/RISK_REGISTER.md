# Risk Register V0.1

| 风险 | 触发信号 | 当前缓解措施 | 优先级 |
| --- | --- | --- | --- |
| 摄像头识别受光照、遮挡或反光影响 | 坐标跳动、Marker 丢失、Path Mask 破碎 | 固定高度与光照；记录阈值；加入稳定帧和短暂丢失容错 | P0 |
| Camera 到 Game 映射不稳定 | 桌面位置与 Unity 位置偏移或翻转 | 使用四角校准；保存校准版本；加入可视化验证点 | P0 |
| Python 与 Unity 通信读取到半写入或旧布局 | JSON 解析失败、旧状态覆盖新状态 | 使用版本号与时间戳；先写临时文件再原子替换 `latest_layout.json`；Unity 拒绝旧时间戳并按周期归档 | P0 |
| DJI Pocket 3 无法以预期方式稳定取流 | OBS 中找不到设备、分辨率或帧率不稳定 | 首次实测前确认 Webcam/USB 模式；保留 iPhone 13 输入方案；识别端只依赖标准视频帧 | P0 |
| 全板视野下四角 Marker 尺寸不足 | 近距离可识别，拍完整块60 × 90 cm板时频繁丢失 | 用原尺寸硬卡完成10次识别测试；优先增大编码区，不先修改算法阈值掩盖问题 | P0 |
| 木片缺口轮廓无法稳定恢复ID或角度 | 缺口与木纹、阴影混淆，Food与Woodland误判 | 使用浅色哑光木面和黑板高对比；方向缺口大于编码缺口；按8个旋转角、每角10帧验收；失败时先增大缺口 | P0 |
| 彩色路径与贴膜、手部或光斑混淆 | Mask 包含固定地图区域或被切成多段 | 使用高饱和哑光色带；比较洋红、青、橙实拍；固定曝光白平衡；记录最终 HSV 范围 | P0 |
| 色带翘起或磁吸点遮挡路径 | 路径宽度变化、拐点附近出现断裂 | 使用扁平罗纹带；磁吸点放在少量关键位置；Confirm 前要求双手离开并稳定 1 秒 | P0 |
| 实体厘米坐标、归一化坐标与 Unity 坐标定义不一致 | x/y 翻转、比例错误、角度方向不一致 | 在数据 schema 中固定左上原点和归一化范围；用四角与 5 个已知测试点做可视化验收 | P0 |
| 玩家把 Food Hotspot 理解为直接投喂 | 参与者描述为“把食物喂给动物”而非规划人类活动条件 | 使用 Human Activity/Food Availability 文案；Brief 先说明来源条件；预测试访谈检查理解 | P0 |
| 约束与分数变成唯一正确答案 | 玩家只追求全部绿色或100分，不再比较取舍 | 分数按人类与三物种分项显示、重复事件封顶且不评价回避；Observe必须同时显示行为解释，后续与Trace并列；预测试记录玩家是否只追分 | P0 |
| 多只代理轨迹过密，遮挡地图或被误读为精确行为数据 | Combined视图成为大片色块，玩家无法区分路线与规划路径 | 0.08 Unity单位间距采样、窄线和半透明显示；Human/Animal/Combined切换；上一轮进一步淡化；预测试记录可读性 | P0 |
| Scope 持续扩大 | P1 工作提前进入、核心循环仍不可演示 | 所有新增项先对照 Project Scope；里程碑延期时删 P1 | P0 |
| 生态表达被误读为精确预测 | 模型参数缺少来源、展示语言过度确定 | 区分生态依据、设计抽象和反思性表现；记录来源与限制 | P0 |
| 用户研究伦理或课程要求不完整 | 招募前材料未确认 | 第一周确认审批、同意、撤回与数据保存要求 | P0 |
| 参与者数据被误提交 | Git 状态中出现原始访谈、同意书或身份信息 | 默认忽略私有数据目录；提交前检查 staged files；只提交脱敏样例 | P0 |
| Unity 构建不可恢复 | 只在一台电脑运行、无版本说明 | 锁定 Unity 版本；记录安装模块；定期从干净环境验证 | P1 |
| 实体部件或支架到货延迟 | 计划测试日前仍无法搭建完整桌面 | 使用纸板轮廓、独立打印校准卡和现成磁铁完成视觉 Spike；最终木件不阻塞 P0 | P0 |
| 研究日志与实现版本脱节 | 无法判断截图、参数和结果对应哪个版本 | 每个 Session 记录 schema、calibration、build 和 scenario 版本；每周整理一次过程证据 | P0 |

## 每周检查

- 当前里程碑是否可以现场演示或验收。
- 是否有未记录的 Scope 变化。
- 是否有私有研究数据进入 Git。
- 是否保留了失败尝试、版本差异和关键参数。
