# Four-Corner Calibration Cards

这些 PNG 是300 dpi、70 × 70 mm的独立校准卡，中央 ArUco 编码区为50 × 50 mm。

- `ID 0`：左上
- `ID 1`：右上
- `ID 2`：右下
- `ID 3`：左下

优先打印上一级目录中的 `aruco-four-corner-calibration-a4.pdf`。打印时选择A4、100%或实际尺寸，关闭“适应页面”和双面打印，并用尺子确认50 mm校验线。

这些文件由 `vision/generate_calibration_markers.py` 生成，不要在图片编辑软件中单独缩放。
