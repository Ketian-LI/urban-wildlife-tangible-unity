## 待确定顺序

1. 实物测试：最终路径颜色与 HSV 阈值、相机高度、镜头视野、曝光和灯具精确位置。
2. 预测试复核：S001 基准布局、Food Hotspot 距离阈值、60/30 秒阶段时长与每 Session 3 周期是否合适。
3. 软件环境验证：创建 `.venv`、安装锁定依赖、验证 `cv2.aruco`，并安装/记录 OBS 版本。
4. 模拟参数：NPC 数量、速度、动物状态持续时间和干扰成本。

每项决定后，需要同步更新 Hardware、Architecture、Project Scope 和当天开发日志中的相关部分。
