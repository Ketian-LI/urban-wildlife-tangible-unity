# Hardware

记录实体操作板、摄像头、支架、Token、彩绳和校准条件。

## 已确定

- 操作板：60 × 90 cm 黑色磁吸板。
- 方向：90 cm 横向、60 cm 纵向，平放在桌面。
- 摄像方式：固定在板面正上方垂直俯拍。
- 初始高度：预计 70 至 100 cm，以完整拍到四角并保留边缘余量为准。
- 校准：四角固定四个 ID 不同的白底 Marker，玩家不可移动。
- P0 制作：允许使用打印件、纸板或轻型材料加现成磁铁，不要求最终木制 Token。

## 待确定

1. 摄像头型号、分辨率、帧率和镜头视角。
2. 俯拍支架的结构与固定方式。
3. ArUco 或 AprilTag，以及 Marker 的实际尺寸。
4. Token 的尺寸、厚度、形状和磁吸方式。
5. 彩绳的颜色、宽度、材质和固定方式。
6. 黑色板面是否直接作为地图，或覆盖灰度地图层。
7. 灯光数量、位置和是否需要柔光。
8. Confirm 操作采用实体按钮、键盘还是屏幕按钮。

第一轮记录至少包括：

- 摄像头型号、分辨率、帧率与固定高度。
- 桌面尺寸、背景颜色和四角校准点。
- 光源位置、时间和环境变化。
- Marker 类型、尺寸、打印或雕刻方式。
- 彩绳颜色及对应 HSV 测试范围。
- 失败照片、反光、遮挡和抖动情况。
