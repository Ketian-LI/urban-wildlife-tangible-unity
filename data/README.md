# Data

此目录只保存数据结构、脱敏样例和可复现的处理脚本。

以下内容不得提交到 Git：

- 参与者姓名、邮箱或其他身份信息。
- 签署的同意书。
- 未脱敏访谈录音、视频、逐字稿或观察记录。
- 包含个人路径或行为记录的原始文件。

建议本地目录：

```text
data/
├─ raw/          原始设备与会话输出
├─ private/      身份对照与敏感记录
├─ interviews/   未脱敏访谈材料
├─ consent/      同意书
├─ processed/    脱敏后的分析数据
└─ samples/      可提交的匿名示例
```

提交任何数据前，先检查课程伦理要求和参与者同意范围。
