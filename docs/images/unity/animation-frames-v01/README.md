# Animation Frame Contact Sheets V0.1

Created on 2026-09-10 with the built-in image generation tool for the first independently drawn Unity action-animation pilot.

- `pigeon-feed-sheet-v01.png`: six pigeon eating poses, 3 x 2, source for `pigeon-side-feed-01-v01.png` through `-06-v01.png`.
- `visitor-feed-sheet-v01.png`: six Visitor feeding poses, 3 x 2, source for `visitor-feed-01-v01.png` through `-06-v01.png`.

The sheets intentionally retain their uniform `#00FF00` isolation background as a generation record. The game-ready cells were split with `tools/split_sprite_sheet.py` and chroma-keyed to true RGBA. Exact final prompts are recorded in the Animals and Humans resource README files beside the active sprites.

The images are prototype assets. Confirm the course's authorship and AI-assisted visual-material policy before final submission.
