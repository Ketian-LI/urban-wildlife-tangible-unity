## 待确定顺序

1. 摄像头：使用现有 USB 摄像头、手机，还是购买专用摄像头。
2. 摄像头支架：桌夹横臂、独立门形框架或其他固定方式。
3. Marker：选择 ArUco 或 AprilTag，并锁定尺寸和打印方式。
4. Token：尺寸、形状、材料、磁铁位置和 Marker 安装面。
5. 彩绳：颜色、宽度、材质、端点固定与交叉处理。
6. 地图表面：黑色底板直接使用，或增加薄型灰度地图覆盖层。
7. 灯光：双侧柔光、环境光控制和曝光锁定方式。
8. Confirm 输入：实体按钮、键盘按键或屏幕按钮。
9. 视觉到 Unity 的通信：JSON 文件、UDP 或 OSC。
10. 软件版本：Unity、Python、OpenCV 与 Marker 库版本。

每项决定后，需要同步更新 Hardware、Architecture、Project Scope 和当天开发日志中的相关部分。
