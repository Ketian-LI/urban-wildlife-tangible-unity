三张 `concept-board` 和 `token-shape-concepts-v01` 为AI辅助生成的概念效果图，不是精确比例图，也不能作为实体制作或计算机视觉已经完成的证据。造型概念图中的圆孔和雕刻只用于比较外观语言，选型前不替代已经通过软件预验证的边缘缺口编码。`token-size-comparison` 使用板面比例比较尺寸，但屏幕显示大小不等于实物大小。`s001-baseline-layout` 是规划示意，不是完成原型的摄像头截图。

学生确定了板面、材料、尺寸、组件含义和修改方向，并审查了图像输出。Codex 与 ImageGen 协助生成和整理图像。四角校准打印文件位于 `hardware/printables/aruco-four-corner-calibration-a4.pdf`。
